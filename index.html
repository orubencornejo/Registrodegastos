    Cómo está hecha esta app

    1. La lista de gastos es un arreglo (array)

    Todo vive en una sola variable: gastos. Cada gasto es un objeto con cuatro datos: descripción, monto, categoría y fecha. Agregar un gasto es tan simple como meter un objeto nuevo al arreglo con push().

    var gastos = [];

var nuevoGasto = {
  descripcion: "Súper de la semana",
  monto: 850.50,
  categoria: "Comida",
  fecha: "2026-11-17"
};

gastos.push(nuevoGasto);
    2. El total se calcula recorriendo el arreglo

    Un ciclo for pasa por cada gasto y suma su monto. Cada vez que la lista cambia, se vuelve a calcular y se repinta la pantalla con la función dibujar().

    function calcularTotal() {
  var total = 0;
  for (var i = 0; i < gastos.length; i++) {
    total = total + gastos[i].monto;
  }
  return total;
}
    3. El botón «Agregar» escucha un evento

    JavaScript escucha lo que hace el usuario. Cuando envías el formulario, se dispara el evento submit: la app lee los campos, valida que no estén vacíos y agrega el gasto.

    formulario.addEventListener("submit", function (evento) {
  evento.preventDefault(); // evita que la página se recargue
  // leer los campos, validar y agregar el gasto…
});
